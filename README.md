# Gwent: The Witcher Card Game Clone

A comprehensive, full-stack desktop implementation of the complex strategy card game "Gwent" (from The Witcher universe), developed from scratch as an Advanced Programming project.

## 🚀 Features
* **Full Game Logic & UI/UX:** Developed completely using Java and JavaFX, replication of game mechanics, card behaviors, and visual layouts.
* **Robust Networking:** Engineered a secure client-server architecture using **Java Socket Programming** supporting steady real-time multiplayer gameplay.
* **Live Chat System:** Integrated an in-game live chat room for players during active matches.
* **Spectator Mode:** Implemented a real-time streaming feature allowing other connected users to watch ongoing live matches.
* **Security & Authentication:** Features a secure user authentication system complete with **Two-Factor Authentication (2FA)** and encrypted password storage.
* **Database Persistence:** Utilizes a structured SQL database to save user profiles, match histories, and global leaderboards.

## 🛠️ Technologies Used
* **Language:** Java
* **GUI Framework:** JavaFX
* **Networking:** Java Sockets (TCP)
* **Database:** SQL
